# 🧪 Simple REST API with Gin (Go)

This is a beginner-friendly REST API project built using the [Gin](https://github.com/gin-gonic/gin) framework in Go. It features basic task management functionality and demonstrates how to build simple web services in Go. It also includes basic HTTP authentication using Gin's built-in middleware.

---

## 🚀 Features

- Built with [Gin Web Framework](https://gin-gonic.com/)
- RESTful API: `GET`, `POST`, and `PATCH` routes for task management
- Simple persistent storage using a local JSON file
- Basic Authentication for protected routes
- Cleanly structured and well-commented for learning purposes
